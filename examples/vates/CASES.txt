LogLens - Vates (XCP-ng / Xen Orchestra) test kit: 6 synthetic cases
==================================================================

HOW TO TEST
1. Unzip. Needs Python 3.9+ only (standard library).
2. cd app ; python -m lvx serve        (Windows: py -m lvx serve)   -> open http://127.0.0.1:8765
3. Drag a bundle from ../bundles into the page, paste the issue text below, set Incident time = 2026-03-10T10:00:00Z, click Analyze.
4. On the top finding: click "Show log context" (raw lines around the match), click "open in viewer" (full file at that line),
   then press Confirm / Reject / Unsure and type a note. Export Markdown/HTML/JSON: the "Reviewer verdict" is in the report.
   (Verdicts are remembered in this browser per bundle + incident time.)

reports/*.html = reference reports produced by the CLI for the same bundles; screenshots/ = Playwright run of case 4 (viewer + confirm controls).
